> Aplicativo mobile que conecta pequenos produtores locais aos consumidores, incentivando a agricultura sustentável e o consumo responsável.

## 🎯 Objetivo do Projeto

Desenvolver um aplicativo mobile que conecte pequenos produtores locais e consumidores, facilitando a divulgação e comercialização de alimentos e incentivando o consumo responsável.

---

## 👥 Público-Alvo

- Pequenos produtores locais, especialmente orgânicos.
- Agricultores familiares.
- Consumidores interessados em alimentação saudável.
- Pessoas interessadas em produtos locais e sustentabilidade.

---

## 🧩 Problema a Ser Resolvido

Pequenos produtores, especialmente os orgânicos, enfrentam dificuldades para divulgar seus produtos, alcançar consumidores e ampliar suas vendas. A falta de conexão entre produtores e consumidores também pode contribuir para o desperdício de alimentos.

---

## 💡 Solução Proposta

O ConectaAgro é um aplicativo mobile que aproxima pequenos produtores dos consumidores por meio de recursos para cadastro, divulgação e busca de produtos, localização por mapa, publicações e realização de pedidos. Também permite divulgar excedentes com preços promocionais, incentivando o consumo consciente e a redução do desperdício.

---

## ⚙️ Funcionalidades do Sistema

### Funcionalidades Principais

- Cadastro de usuários e produtores.
- Login no sistema.
- Cadastro e divulgação de produtos.
- Edição de dados e produtos.
- Exclusão de registros.
- Pesquisa e busca de produtos e produtores.
- Localização de produtores por mapa.
- Divulgação de excedentes agrícolas.
- Publicações e interação entre usuários.
- Realização e gerenciamento de pedidos.
- Controle de acesso por perfil.

## 🧪 Requisitos Funcionais

- **RF01** – O sistema deve permitir cadastrar usuários e produtores.
- **RF02** – O sistema deve permitir realizar login.
- **RF03** – O sistema deve permitir cadastrar, editar e excluir produtos.
- **RF04** – O sistema deve permitir pesquisar produtos e produtores.
- **RF05** – O sistema deve apresentar a localização dos produtores.
- **RF06** – O sistema deve permitir divulgar excedentes agrícolas.
- **RF07** – O sistema deve disponibilizar publicações e interação entre usuários.
- **RF08** – O sistema deve permitir a realização de pedidos.
- **RF09** – O sistema deve permitir o gerenciamento das informações dos usuários.

---

## 🚫 Requisitos Não Funcionais

- O aplicativo deve apresentar interface simples e intuitiva.
- O sistema deve ser compatível com dispositivos móveis.
- O banco de dados deve estar disponível online.
- O sistema deve garantir a segurança das informações.
- O aplicativo deve apresentar bom desempenho na navegação.
- O código deve ser organizado e facilitar futuras atualizações.

## 📦 Como Executar o Projeto

O ConectaAgro pode ser acessado por meio do link de download disponibilizado pela equipe ou executado localmente em um ambiente de desenvolvimento.

### Acesso e download do aplicativo

O aplicativo possui uma versão instalável para dispositivos móveis, disponibilizada por meio do Expo.

1. Acesse o link de download.
2. Baixe o arquivo de instalação disponibilizado.
3. Instale o aplicativo no dispositivo compatível.
4. Abra o ConectaAgro para utilizar suas funcionalidades.

**Link para download:** [Baixar ConectaAgro](https://expo.dev/accounts/liviamaga/projects/ConectaAgro/builds/c67565e6-4005-47f4-8380-502facf43246)

### Execução local

**Pré-requisitos:**

- Node.js instalado.
- npm instalado.
- Visual Studio Code.

**Passo a passo:**

1. Clone o repositório:

```bash
git clone https://github.com/liviamags/ConectaAgro.git
```

2. Acesse a pasta do projeto:

```bash
cd ConectaAgro
```

3. Instale as dependências:

```bash
npm install
```

4. Configure as variáveis de ambiente necessárias para conexão com o Supabase.

5. Inicie o projeto:

```bash
npx expo start
```
